На момент запуска плейбука на сервере должно быть:
  1) Настроен домен;
  2) Добавлен юзер, от лица которого будет проводится работа;
  3) Настроен фаерволл (ufw).

Инструкция по развертыванию сервера
  1) Арендуем сервер;
  2) Прописываем А и AAAA DNS записи;
  3) Запуск плейбука initial-setup.yml, в нем настривается:
    3.1) user - deploy;
    3.2) фаерволл(ufw);
    3.3) агент забикса отдельным playbook'ом (не забыть на сервере забикса обновить адрес нового агента).
    *команда для запуска плейбука
    ansible-playbook -i inventory.ini playbooks/initial-setup.yml --limit first_test --ask-vault-pass
  4) Запуск плейбука restore_site.yml, в нем:
    4.1) Подготовка окружения (php8.1-fpm, mariadb, nginx);
    4.2) Создание БД для Wordpress;
    4.3) Копирование файлов бэкапа на новый сервер;
    4.4) Конфигурация Nginx и создание сертификатов через certbot.
    *команда для запуска плейбука
    ansible-playbook -i inventory.ini restore_site.yml --limit test --ask-vault-pass
  5) Переходим по адресу финспэйс.рф/installer.php и восстанавливаемся из бэкапа;
  6) Сайт работает!
